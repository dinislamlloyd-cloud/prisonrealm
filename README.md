# Prison Kingdom (Тюремное царство)

Мод для **Fabric 1.20.1** (нужен Fabric Loader 0.15+ и Fabric API).

## Как получить .jar

**Вариант A: через GitHub (ничего ставить не надо)**
1. Создайте на github.com пустой репозиторий.
2. Загрузите в него все файлы из этого архива (Add file → Upload files), включая папку `.github`.
3. Откройте вкладку **Actions** → сборка `build` → через 2–3 минуты внизу страницы будет артефакт `prison-kingdom-mod`.
4. Скачайте, распакуйте и возьмите файл `prisonrealm-1.0.0.jar`.

**Вариант B: локально**
1. Установите JDK 17 и Gradle 8.5 (или откройте папку в IntelliJ IDEA, она всё подтянет сама).
2. В папке проекта выполните `gradle build`.
3. Готовый мод: `build/libs/prisonrealm-1.0.0.jar`.

## Установка
Положите `.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) для 1.20.1 в папку `mods`. Мод нужен и на сервере, и у игроков.

## Что в моде
**Предметы**
- **Запечатывающий куб** — работает на игроках и мобах. ПКМ кубом по цели (или ПКМ в воздух, глядя на цель до 12 блоков): перед целью раскрывается печать — крест с большим глазом и кубами на концах лап, из неё тянутся щупальца и держат цель. Через 3 секунды печать складывается и исчезает, и вокруг цели появляются шесть красных кубов с глазами со своими щупальцами. **Ещё раз ПКМ** (или «close» в чат): кубы растут, наваливаются на цель со всех сторон, затем сдвигаются в один куб — цель исчезает внутри, куб сжимается. Если не закрыть за 20 секунд, печать рассеивается. Перезарядка 20 секунд. Где взять в выживании: выбросите (Q) на землю рядом друг с другом 3 обсидиана и 3 красных красителя — они сольются в куб; или скрафтите на верстаке из 3 обсидиана и 3 красных красителей (в любом порядке). Также есть в творческой вкладке «Тюремное царство» и через `/give @s prisonrealm:sealing_cube`.
- **Голубой куб** — остаётся на месте запечатывания. Любой игрок в 2 блоках пишет в чат **open**, и цель выходит на этом месте. Игрок без «open» выйдет через 10 минут, моб сидит в кубе, пока не откроют.
- **Наручники** — ПКМ по игроку, которого замедлила дубинка или у которого меньше 3 сердец. Срок 5 минут.
- **Дубинка стражника** — слабый урон, но замедляет цель.
- **Тюремный ключ** — открывает решётку камеры и ворота.

**Блоки:** тюремный кирпич, решётка, лампа, расшатанный кирпич, тюремные ворота.

**Тюремное измерение** `prisonrealm:prison` строится само при первом аресте: двор, блок из 5 камер, караулка с сундуком и ворота.

**Побег**
1. В камере ПКМ по расшатанному кирпичу на задней стене даёт ключ.
2. Ключом ПКМ по решётке открывается камера.
3. В караулке (справа во дворе) в сундуке второй ключ.
4. Ключом ПКМ по воротам на южной стене: вы на свободе, но светитесь 3 минуты.

Пока вы в тюрьме, ваши вещи хранятся и вернутся при освобождении. Заключённые не могут драться, ломать и ставить блоки.

**Команды**
- `/prison arrest <игрок> [минуты]` — арестовать (оператор)
- `/prison seal <игрок>` — запустить анимацию куба на игроке (удобно проверить на себе, оператор)
- `/prison release <игрок>` — освободить (оператор)
- `/prison list` — список заключённых (оператор)
- `/prison time` — сколько осталось вам
